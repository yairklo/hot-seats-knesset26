# מקומות חמים בסקרים – הכנסת ה-26

כלי שמציג אילו מועמדים לכנסת ה-26 נמצאים סביב קו המנדטים, לפי כל סקר ולפי ממוצע הסקרים, עם פילוח לפי מגדר.

## הרצה

הדף טוען קובצי JSON, ולכן צריך שרת מקומי (פתיחה ישירה מהדיסק נחסמת על ידי הדפדפן):

```bash
cd hot-seats
python -m http.server 8766
```

ואז לפתוח http://localhost:8766. ייצוא ה-PNG טוען את `html-to-image` מ-jsDelivr, ולכן צריך חיבור לאינטרנט.

## מבנה

| קובץ | תוכן |
|---|---|
| `hot-seats/index.html` | הדף והעיצוב |
| `hot-seats/app.js` | כל הלוגיקה: בחירת מקור, ממוצע, ספירות, השוואה, ייצוא |
| `hot-seats/polls.json` | הסקרים, ומיפוי שמות המפלגות מאנגלית לעברית (`partyMap`) |
| `hot-seats/candidates.json` | 32 המקומות הראשונים בכל רשימה, עם מגדר לכל מועמד |
| `hot-seats/candidate-details.json` | פרטים לכרטיס המועמד (תקציר, קישורים ותמונה מוויקיפדיה), במפתח `"<מפלגה>\|<מקום>"`. לא חובה: בלעדיו הכרטיס מציג "אין מידע נוסף זמין" |

## הגדרות (לא לשנות)

- **בתוך הקו:** מקומות 1 עד N, כש-N הוא מספר המנדטים בסקר.
- **טווח חם:** מקומות N-2 עד N+2. טווח 1± הוא N-1 עד N+1.
- **נכנס בבטחה ("בפנים"):** מקומות 1 עד N-3.
- **ממוצע הסקרים:** ממוצע המנדטים לכל מפלגה על פני כל הסקרים, כשסקר שבו המפלגה מתחת לאחוז החסימה נספר כ-0. מפלגה שהממוצע המעוגל שלה נמוך מ-4 מוצגת כמתחת לאחוז החסימה ומקבלת 0. בין שאר המפלגות מחולקים בדיוק 120 מנדטים לפי שיטת השארית הגדולה, ביחס לממוצעים שלהן. הממוצע המדויק מוצג ליד המספר.
- **כוכבית:** מפלגה עם פחות מ-6 מנדטים, קרובה לאחוז החסימה.

## נתונים

- **סקרים:** מתוך טבלת הסקרים לבחירות 2026 בוויקיפדיה האנגלית. `null` = מתחת לאחוז החסימה. כדי להוסיף סקר, מוסיפים אובייקט ל-`polls`. מפלגה חדשה צריכה גם רשומה ב-`partyMap` ורשימה ב-`candidates.json`.
- **מועמדים:** מתוך רשימות המועמדים שפורסמו באתר ועדת הבחירות המרכזית (gov.il), 32 המקומות הראשונים בכל רשימה (או כל הרשימה אם היא קצרה יותר). לכל מפלגה נשמרים `url` ותאריך העדכון של הרשימה (`listUpdated`). `tools/official-lists.json` הוא העותק הגולמי מהאתר שממנו נבנה הקובץ. כחול לבן ותנועת אחי פרשו מההתמודדות ולכן לא נכללות. `official` הוא השם כפי שמופיע ברשימה הרשמית (שם משפחה קודם), ו-`display` הוא שם לתצוגה כשהוא לא נגזר אוטומטית.
- **מגדר:** `F` אישה, `M` גבר, `null` לא אומת. המגדר נקבע לפי השם ונבדק ידנית בחיפוש לגבי שמות שלא היו חד-משמעיים. שמות עם `null` לא נבדקו עד הסוף, והכלי מציג עליהם אזהרה ולא מנחש.
- **מגבלה:** יש נתונים רק ל-32 המקומות הראשונים. כשהטווח החם חורג מזה (מפלגה עם יותר מ-30 מנדטים), הכלי מציג אזהרה.
